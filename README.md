# dorning.me

https://dorning.me — games and tools by Cory Dorning. Aces Only Golf lives at /aces-only/. The homepage also lists OAIA Studio, a local macOS image app and installable skill for Codex and Claude Code, with links to its GitHub project and release ZIP.

`app-ads.txt` at the root is the AdMob publisher record for every game listed on dorning.me.
